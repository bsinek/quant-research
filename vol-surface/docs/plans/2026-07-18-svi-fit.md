# Raw SVI fit (per-expiry)

**Date:** 2026-07-18
**Scope:** raw SVI fitted independently per expiry, on the pinned 2026-07-13 SPX snapshot.
SSVI is a separate later plan; this one deliberately stops at the point where its
motivation becomes measurable.

## Goal

Replace the raw IV scatter in `surface.ipynb` with a fitted curve per expiry: each
expiry's ~200 noisy quotes compressed to 5 parameters that can be evaluated at any
strike, checked for butterfly arbitrage analytically, and stacked into a smooth surface.

## Why a parametric fit rather than interpolation

A spline through every quote inherits the quotes' bid-ask noise. Butterfly arbitrage is
a condition on the *second* derivative of call prices, and second differences scale with
the square of the strike gap while the noise on each quote does not — so in the dense,
tight-spread ATM region the true curvature is small relative to its own error, and an
interpolant manufactures violations there. A 5-parameter fit has too little freedom to
reproduce noise. Its wings are also linear in `k`, which is the asymptotic behaviour
theory requires; a spline's are arbitrary.

## Coordinates

- `k = ln(K / F)` — log-moneyness, off the existing parity forward.
- `w = σ² T` — total variance. Variance is linear in `T` and therefore additive across
  time windows; vol is not. Every no-arbitrage condition we care about is simple in `w`
  and awkward in `σ`. Within one expiry `T` is constant, so this is a rescaling.

## Module: `engine/svi.py`

Pure functions, matching the existing `engine/` pattern (vectorized, no state, docstrings
carrying the *why* and — where a DataFrame is returned — its columns).

```
svi_w(k, a, b, rho, m, sigma)   → total variance at k. Vectorized.
fit_slice(k, w, weight)         → (a, b, rho, m, sigma), rmse — ONE expiry.
fit_surface(df)                 → DataFrame: one row per expiry, params + diagnostics.
svi_g(k, params)                → Gatheral g(k); butterfly-clean iff ≥ 0 everywhere.
```

### `fit_slice` — Zeliade quasi-explicit

Substituting `y = (k − m)/σ` collapses the model to

```
w = a·1 + c·y + d·√(y² + 1)        where c = bρσ,  d = bσ
```

which is **linear** in `(a, c, d)` once `(m, σ)` are fixed. So:

- **inner** — given `(m, σ)`, build the design matrix `[1, y, √(y²+1)]` and solve by
  weighted `lstsq`. Closed form, exact, non-iterative.
- **outer** — Nelder-Mead over `(m, σ)` only, objective = the inner weighted residual.
- **unpack** — `b = d/σ`, `ρ = c/d`.

This reduces a fragile 5-D non-convex search to a 2-D one with an exact solve inside.
Handing all five parameters to an optimizer is not slower, it is *wrong more often*: it
converges confidently into local minima, and across 55 expiries some fraction will do so
silently. The residual 2-D space is small enough to scan exhaustively if Nelder-Mead is
ever doubted.

Starting values come from the data, not constants: `m₀` ≈ the `k` of the lowest observed
`w`, `σ₀` ≈ the width of the quoted `k` range.

### Weighting

Quotes are not equally informative — median relative spread runs ~1.6% near ATM against
~7.3% in the wings, so unweighted least squares lets the least-known prices pull hardest.
But the mismatch is deeper than spread width: the spread is a *price* uncertainty and the
fit lives in *total-variance* space, and the conversion between them is vega:
`vol uncertainty = spread / vega`. A given spread on a high-vega option carries *more*
vol information than the same spread on a low-vega one, because the price is more
responsive to vol there. Vega and spread are independent and both measured per quote, so
the weight assumes nothing about where wide spreads sit. The principled weight combines
both effects:

```
weight = vega / max(ask − bid, tick)
```

The `tick` floor (0.05) guards against a zero-width spread sending one quote's weight to
infinity. This needs `bs_vega`, a one-line addition to `blackscholes.py` reusing the `d₁`
already computed in `bs_price` — promoted from the deferred list because it pays off twice:
the weighting here, and the deferred safeguarded-Newton IV solver, whose update step
`σ − (price(σ) − mkt)/vega` divides by exactly this quantity. `vega/spread` is the analytic
form of the vol-uncertainty band; the equivalent exact-but-approximation-free measurement
is to invert bid and ask separately and take the IV gap (the diagnostic plot does this).

**Weight power is a knob, not a law.** Strict inverse-variance (`(vega/spread)²`) is
statistically optimal but concentrates weight on ATM and starves the skew-bearing wings.
Start at the first power (`vega/spread`, i.e. inverse-*std*), which keeps the wings in the
fit; move toward the square only if ATM ends up loose. This tradeoff — softening from
inverse-variance to preserve the wing/skew fit — is the defensible choice to record.

Fallback if vega weighting misbehaves on the wings: plain `1 / max(ask − bid, tick)`.
Both are cheap; start with vega, drop to inverse-spread only if the wings over- or
under-fit.

### No-arbitrage handling

Two layers:

- **during the fit** — parameter bounds: `b ≥ 0`, `|ρ| < 1`,
  `a + bσ√(1−ρ²) ≥ 0`, `b(1+|ρ|) ≤ 4/T`.
- **after the fit** — evaluate `g(k)` analytically on a fine grid per expiry. SVI has a
  closed form, so `w′` and `w″` are exact derivatives; no finite differences, no noise.

  Verified against Gatheral & Jacquier, *Arbitrage-free SVI volatility surfaces*
  (arXiv:1204.0646), Lemma 2.2:

  ```
  g(k) = (1 − k·w′/(2w))²  −  (w′²/4)·(1/w + 1/4)  +  w″/2
  ```

  A slice is butterfly-arbitrage-free iff `g(k) ≥ 0` for all `k`, together with
  `d₊(k) → −∞` as `k → ∞`. `g(k)` is a processed form of the risk-neutral density, which
  is why its non-negativity is the condition.

Calendar arbitrage is **not** enforced here. Independent per-expiry fits cannot see each
other, so crossings are possible by construction. Measuring where they occur is a
deliverable of this plan, not a defect of it.

### Error handling

An expiry with fewer than 8 quotes is skipped, with `NaN` params recorded rather than a
garbage fit — same spirit as `forward_by_expiry` dropping expiries with no paired
strikes. `fit_surface` returns per-expiry diagnostics so poor fits surface in the table
instead of silently entering the surface plot.

## Data flow

```
clean OTM quotes (iv, T, F, strike, bid, ask)     ← existing surface.ipynb pipeline
  → k = ln(K/F),  w = iv²·T,  weight = 1/(ask−bid)
  → per expiry: fit_slice                          →  55 × 5 params
  → svi_g on a fine k-grid                         →  butterfly check per expiry
  → w monotonic in T at fixed k                    →  calendar check (expected to fail)
  → evaluate on a regular (k, T) grid              →  smooth 3-D surface
```

## Validation

In-notebook, matching how the bisection solver was validated against `cboe_iv` (ADR 010).
No pytest — the repo has no test infrastructure and adding it is out of scope here.

## Acceptance criteria

1. **Synthetic round-trip.** Generate `w` from known SVI parameters over a realistic `k`
   range, add noise at the scale of the observed spreads, refit, and confirm recovery to
   within 0.1 vol points at every `k` in the fitted range — comfortably tighter than the
   ~0.14 vol-point median agreement the bisection solver reached against `cboe_iv`.
   Assert on the **curve** (`max |w_fit − w_true|` across the `k` range), not on the
   individual parameters — SVI parameters trade off against one another, so parameter-wise
   comparison can fail on a curve that is correct.
2. **Butterfly.** `g(k) ≥ 0` across the quoted `k` range for every fitted expiry.
3. **Coverage.** Every expiry with ≥ 8 quotes yields finite parameters; the count of
   skipped expiries is reported, not silent.
4. **Fit quality.** Weighted RMSE reported per expiry in vol points. Expiries above 1 vol
   point are flagged for inspection rather than hard-failing — the threshold is a
   starting guess, not a measured tolerance.
5. **Calendar diagnostic.** Total variance checked for monotonicity in `T` at fixed `k`.
   Violations are expected at some expiries; where they occur is recorded, and becomes
   the empirical motivation for the SSVI plan.
6. **Visual.** Fitted curves overlaid on the raw dots per expiry, plus the resampled
   smooth 3-D surface beside the existing scatter.
