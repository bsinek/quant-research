# Plans (archive)

> Dated implementation plans — one per feature/sprint. Naming: `YYYY-MM-DD-<slug>.md`.
> Acceptance criteria live inside the plan (before building) and become the tests.
>
> These are HISTORY, not current truth. Current behavior lives in the **code (docstrings)**
> and `../ARCHITECTURE.md`; the "why" lives in `../DECISIONS.md`. Never read an old plan as
> the current state — it's a snapshot of what was built then.
